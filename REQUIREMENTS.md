| React | React 19, TypeScript, Vite |

## Ожидаемый сценарий

1. Ввод `idInstance`, `apiTokenInstance` и `apiUrl` своего инстанса.
2. Ввод телефона получателя; `CheckAccount` возвращает MAX `chatId`.
3. Отправка текста методом `SendMessage`.
4. Получатель отвечает в обычном MAX.
5. Ответ автоматически появляется в соответствующем веб-чате.

Код всех шагов реализован. Обмен с реальным аккаунтом требует проверки с собственными учётными данными: [MANUAL_TESTING.md](MANUAL_TESTING.md).
